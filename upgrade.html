Upgrade contract

Point an upgradeable vault (proxy) at a new implementation. Only the owner can do this. The vault address that miners use does not change.

Danger zone. A bad implementation can lock funds or break claims. Test on a small vault first. Confirm you are the owner of the proxy.
This page only works with the upgradeable vault (proxy + implementation). The original simple (non-upgradeable) vault cannot be upgraded — deploy a new one instead.

How upgrades work

  1. Compile & deploy a new implementation contract (logic only)
  2. Paste the proxy (vault) address and the new implementation address
  3. Owner confirms upgradeTo (or upgradeToAndCall)
  4. Miners keep using the same vault address — no migration needed
